## Daily Report Day 4: Building & Deploying Personal Portfolio Project

### 1. Project Initialization & Structure
- Initialized the project folder using pure HTML, CSS, and JS.
- Set up local Git and connected to the remote repository on GitHub (`my-portfolio`).

### 2. Main Content Implementation (UI/UX)
Based on the ideas and designs from Day 3, I completed the entire UI with a modern Light/Dark Theme and Pill-shape rounded corners:
- **Navbar & Hero Section:** Floating navigation bar, greeting, Backend Developer job title introduction, and call-to-action buttons (CV, Contact).
- **Quotes & Bio:** A section displaying personal life quotes and career orientation.
- **Tech Stack:** A 4-box grid showcasing proficient Backend technologies (C# / .NET, Node.js / TS, AWS, Databases) paired with illustrations.
- **Projects:** Showcasing 6 representative projects (PRM393, Edu-Nexus, PiedTeam, RAG-Financial, Serverless Student Mgmt, DNA-Testing) with modern rounded cards and direct Github links.
- **Contact & Footer:** A prominent email contact button and a copyright footer.

### 3. Effects & Optimization (Animation)
- Hand-coded pure CSS to create smooth animations without needing external libraries:
  - An interactive, blurry gradient blob that follows the mouse cursor (Interactive Mouse Blob) which is incredibly eye-catching.
  - Continuous glowing animation (Shine Text) for the personal name.
  - Smooth underline sliding effect (`transform: scaleX`) for the navigation bar.
  - Smooth image enlargement (Zoom in) when hovering over Project cards.
